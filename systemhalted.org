* Overview

Edit this file; =systemhalted.el= is generated. It loads top to bottom — open a
section with =TAB=, fold it when done. =C-c e= visits this file, =C-c r= saves,
tangles, and reloads it.

Startup has three owners: =early-init.el= prepares package activation and the
first frame, =init.el= checks the generated file's freshness, and this file
does the rest.

* Core

Startup, packages, basic editing, and configuration commands.

** Startup and packages

=early-init.el= disables automatic package activation; =package-initialize=
below owns activation. GNU, NonGNU, MELPA, and MELPA Stable are configured in
priority order. Archive packages declare =:ensure t=; built-ins and local
checkouts use =:ensure nil=; =:vc= handles Git installs.

Install failures are reported without an automatic retry: on a stale-metadata
miss run =M-x package-refresh-contents=, then =M-x package-install=, then
restart. =test/package-error-check.el= records =use-package= failure warnings
for the batch checks; it is test scaffolding and loads before =init.el=, not
from here.

Custom state lives in ignored =var/custom.el=. Keep intentional settings here.
Native compilation warnings are kept out of the Warnings buffer; inspect
=*Native-compile-Log*= when investigating compilation failures.

#+begin_src emacs-lisp
;;; systemhalted.el --- Personal Emacs configuration -*- lexical-binding: t; -*-

(setq gc-cons-threshold (* 50 1000 1000))

(setq native-comp-async-report-warnings-errors 'silent)

(defun systemhalted/startup--finish ()
  "Restore the normal GC threshold and report startup time."
  (setq gc-cons-threshold (* 2 1000 1000))
  (message "Emacs loaded in %.2f seconds with %d garbage collections."
           (float-time (time-subtract after-init-time before-init-time))
           gcs-done))

(add-hook 'emacs-startup-hook #'systemhalted/startup--finish)
;; A reload has no subsequent startup hook to restore this threshold.
(when after-init-time
  (setq gc-cons-threshold (* 2 1000 1000)))

(setq custom-file (expand-file-name "var/custom.el" user-emacs-directory))
(make-directory (file-name-directory custom-file) t)
(when (file-exists-p custom-file)
  (load custom-file))

(require 'package)
;; `package-enable-at-startup' is set to nil in early-init.el — it must be
;; off before startup's automatic activation pass, which precedes this file.
(setq package-archives '(("gnu" . "https://elpa.gnu.org/packages/")
                         ("nongnu" . "https://elpa.nongnu.org/nongnu/")
                         ("melpa" . "https://melpa.org/packages/")
                         ("melpa-stable" . "https://stable.melpa.org/packages/"))
      package-archive-priorities '(("gnu" . 30)
                                   ("nongnu" . 25)
                                   ("melpa" . 20)
                                   ("melpa-stable" . 10)))
(package-initialize)
(unless package-archive-contents
  (package-refresh-contents))

(unless (package-installed-p 'use-package)
  (package-install 'use-package))
(require 'use-package)
(setq use-package-always-ensure nil)

(defun systemhalted/personal-package-checkout (env-var)
  "Return the directory ENV-VAR names, as a directory name, when it exists."
  (let ((dir (getenv env-var)))
    (and dir (file-directory-p dir) (file-name-as-directory dir))))

(defmacro systemhalted/use-personal-package (name env-var url local-extras
                                                  &rest body)
  "Declare NAME from the checkout ENV-VAR names, or install it from URL.
BODY holds the `use-package' keywords both branches share; LOCAL-EXTRAS holds
extra keywords spliced into the checkout branch only (nil when there are none).
The branch is chosen at load time, never at expansion time — a tangle compiled
on one machine has to stay correct on a machine that exports a different set of
checkout variables."
  (declare (indent 4))
  ;; `load-path' is extended here rather than from `:preface', which
  ;; `use-package' evaluates at *compile* time — that would bake the build
  ;; machine's environment into the tangle.
  `(if-let* ((dir (systemhalted/personal-package-checkout ,env-var)))
       (progn
         (add-to-list 'load-path dir)
         (use-package ,name :ensure nil ,@local-extras ,@body))
     (use-package ,name
       ;; :rev :newest tracks the latest commit; `use-package-vc-prefer-newest'
       ;; is nil by default, which would pin to a release tag.
       :vc (:url ,url :rev :newest)
       ,@body)))
#+end_src

** Editor defaults and runtime files

Dashboard supplies the startup screen; scratch stays in Lisp Interaction mode.
Backups and auto-saves live in ignored directories under =user-emacs-directory=,
created here for fresh installations. Lock files are disabled to avoid confusing
external file watchers; this also disables their concurrent-edit protection.

Most confirmation prompts accept =y= or =n=. Quitting Emacs deliberately requires
a typed "yes" to protect against an accidental =C-x C-c=.

        auto-save-file-name-transforms `((".*" ,(expand-file-name "auto-save-list/" user-emacs-directory) t))
        create-lockfiles nil
        frame-resize-pixelwise t
        delete-old-versions t
        kept-new-versions 3
        kept-old-versions 2
        version-control t)

  ;; Create the local state dirs so auto-save never fails on a fresh
  ;; clone or after the state directories are wiped.
  (dolist (dir (list (expand-file-name "backups/" user-emacs-directory)
                     (expand-file-name "auto-save-list/" user-emacs-directory)))

** Line numbers, gated to safe buffers

Line numbers are enabled only for local =prog-mode= files below 1 MiB whose
first 2,000 lines all stay under 1,000 characters — limits that keep redisplay
cheap in large or machine-generated buffers. =C-c E= turns them off everywhere.

#+begin_src emacs-lisp
  (defcustom systemhalted/line-number-max-buffer-size (* 1024 1024)
    "Maximum buffer size where line numbers are enabled automatically."
    :type 'integer
    :group 'systemhalted)

  (defcustom systemhalted/line-number-max-line-length 1000
    "Maximum sampled line length where line numbers are enabled automatically."
    :type 'integer
    :group 'systemhalted)

  (defun systemhalted/long-line-buffer-p ()
    "Return non-nil when the current buffer has unusually long sampled lines."
    (> (systemhalted/buffer-longest-line-sample
        nil systemhalted/line-number-max-line-length)
       systemhalted/line-number-max-line-length))

  (defun systemhalted/display-line-numbers-eligible-p ()
    "Return non-nil when line numbers are useful and unlikely to hurt redisplay."
    (and (derived-mode-p 'prog-mode)
         buffer-file-name
         (not (file-remote-p buffer-file-name))
         (< (buffer-size) systemhalted/line-number-max-buffer-size)
         (not (systemhalted/long-line-buffer-p))))

  (defun systemhalted/display-line-numbers-maybe ()
    "Enable line numbers only in normal local code buffers."
    (when (systemhalted/display-line-numbers-eligible-p)
      (display-line-numbers-mode 1)))

  (defun systemhalted/display-line-numbers-disable-all ()
    "Disable line numbers in every live buffer."
    (interactive)
    (dolist (buffer (buffer-list))
      (with-current-buffer buffer
        (when (bound-and-true-p display-line-numbers-mode)
          (display-line-numbers-mode -1)))))

  (add-hook 'prog-mode-hook #'systemhalted/display-line-numbers-maybe)
#+end_src

** Diagnostics and the emergency UI reset

When the UI starts to degrade — sluggish redisplay, climbing RSS,
unresponsive minibuffer — these helpers tell you what's running and let
you shed the expensive bits without restarting Emacs.

=M-x systemhalted/diagnostics= returns an alist: uptime, buffer size and
longest-line sample, active minor modes, LSP state, timer counts, GC counter,
memory summary.

=C-c E= (=systemhalted/emergency-ui-reset=) is the turn-it-off button. It
disables line numbers everywhere, stops =global-auto-revert-mode=, kills
Flycheck / LSP / =mixed-pitch= / =olivetti= in every buffer, then forces a GC.
Fully reversible: reopening a file re-runs the hooks. The binding is =C-c E=
and not =C-c != because Org and Flycheck both own =C-c != in their mode maps,
which beat the global map in exactly the buffers that get heavy.

If Emacs is too unresponsive for =C-c E= to fire, sample it from a terminal
(macOS):

#+begin_src sh
sample <pid> 5 -file /tmp/emacs-hang-sample.txt
#+end_src

On Linux the equivalent is =sudo perf record -F 99 -p <pid> -- sleep 5=
followed by =perf report=, or =py-spy dump --pid <pid>= for a one-shot
backtrace if =py-spy= happens to be installed.

#+begin_src emacs-lisp
  (defun systemhalted/buffer-longest-line-sample (&optional line-limit stop-above)
    "Return the longest line length found in the first LINE-LIMIT lines.
Stop as soon as a line longer than STOP-ABOVE is seen, so callers that only
need a yes/no answer do not scan the whole sample."
    (save-excursion
      (save-restriction
        (widen)
        (goto-char (point-min))
        (let ((remaining (or line-limit 2000))
              (longest 0))
          (while (and (> remaining 0)
                      (not (eobp))
                      (not (and stop-above (> longest stop-above))))
            (setq longest (max longest (- (line-end-position) (line-beginning-position))))
            (setq remaining (1- remaining))
            (forward-line 1))
          longest))))

  (defun systemhalted/active-minor-modes ()
    "Return active minor modes for the current buffer."
    (seq-filter (lambda (mode)
                  (and (boundp mode) (symbol-value mode)))
                minor-mode-list))

  (defun systemhalted/memory-summary ()
    "Return a compact memory summary for diagnostics."
    (memory-use-counts))

  (defun systemhalted/diagnostics ()
    "Return runtime diagnostics for investigating slow or memory-heavy sessions."
    (interactive)
    (let ((report
           `((uptime-seconds . ,(float-time (time-subtract (current-time) before-init-time)))
             (current-buffer . ,(buffer-name))
             (major-mode . ,major-mode)
             (buffer-file . ,buffer-file-name)
             (buffer-size . ,(buffer-size))
             (line-count . ,(count-lines (point-min) (point-max)))
             (longest-line-sample . ,(systemhalted/buffer-longest-line-sample))
             (display-line-numbers . ,(bound-and-true-p display-line-numbers-mode))
             (active-minor-modes . ,(systemhalted/active-minor-modes))
             (lsp-mode . ,(bound-and-true-p lsp-mode))
             (timers . ,(length timer-list))
             (idle-timers . ,(length timer-idle-list))
             (garbage-collections . ,gcs-done)
             (memory . ,(systemhalted/memory-summary)))))
      (when (called-interactively-p 'interactive)
        (message "%s" report))
      report))

  (defun systemhalted/emergency-ui-reset ()
    "Disable expensive UI/runtime features and run garbage collection."
    (interactive)
    (systemhalted/display-line-numbers-disable-all)
    (when (bound-and-true-p global-auto-revert-mode)
      (global-auto-revert-mode -1))
    (dolist (buffer (buffer-list))
      (with-current-buffer buffer
        (when (bound-and-true-p flycheck-mode)
          (ignore-errors (flycheck-mode -1)))
        (when (bound-and-true-p lsp-mode)
          (ignore-errors (lsp-disconnect)))
        (when (bound-and-true-p mixed-pitch-mode)
          (ignore-errors (mixed-pitch-mode -1)))
        (when (bound-and-true-p olivetti-mode)
          (ignore-errors (olivetti-mode -1)))))
    (garbage-collect)
    (message "Emergency UI reset complete: %S" (systemhalted/memory-summary)))

  ;; Not C-c !: that is Org's timestamp key and Flycheck's command prefix,
  ;; and their mode maps would shadow the global binding.
  (global-set-key (kbd "C-c E") #'systemhalted/emergency-ui-reset)
#+end_src

** Reload and visit the literate file

=C-c e= opens this file; =C-c r= saves and reloads it. Reload cannot undo
removed hooks, advice, or bindings, and a failed reload leaves the session
partly updated — restart Emacs after removing behavior or changing a package
source.

#+begin_src emacs-lisp
  (defun systemhalted/config-visit ()
    "Open the literate Emacs configuration."
    (interactive)
    (find-file (expand-file-name "systemhalted.org" user-emacs-directory))
    (olivetti-mode 1))
  (global-set-key (kbd "C-c e") #'systemhalted/config-visit)

  (defun systemhalted/config-reload ()
    "Save and reload the literate Emacs configuration."
    (interactive)
    (let* ((config-file (expand-file-name "systemhalted.org" user-emacs-directory))
           (config-buffer (get-file-buffer config-file)))
      (when (and config-buffer (buffer-modified-p config-buffer))
        (with-current-buffer config-buffer
          (save-buffer)))
      (message "Reloading Emacs configuration...")
      (org-babel-load-file config-file)
      (message "Reloaded Emacs configuration.")))
  (global-set-key (kbd "C-c r") #'systemhalted/config-reload)
#+end_src

** Clipboard

GUI Emacs already shares the host clipboard on every windowed backend. Three
options add the polish: =save-interprogram-paste-before-kill= pushes the host
clipboard onto the kill ring /before/ an Emacs kill overwrites it, so an
external copy stays recoverable through =M-y=; =yank-pop-change-selection=
mirrors the =M-y= result back out; =kill-do-not-save-duplicates= keeps repeated
identical kills out of the ring.

Terminal Emacs reaches no display server, so =xclip= bridges it (=pbcopy= on
macOS, =xclip= / =xsel= on X11, =wl-copy= on Wayland). It activates only in
interactive non-graphical sessions where the executable exists; batch runs keep
the plain kill ring.

#+begin_src emacs-lisp
(setq select-enable-clipboard t
      select-enable-primary nil
      save-interprogram-paste-before-kill t
      yank-pop-change-selection t
      kill-do-not-save-duplicates t)

(use-package xclip
  :ensure t
  :if (and (not noninteractive) (not (display-graphic-p)))
  :config
  (when (executable-find xclip-program)
    (xclip-mode 1)))
#+end_src

** Text Manipulation

Three keys for the line-shape edits that come up constantly: reorder,
duplicate, join. Small enough to belong at the editor layer rather than in a
structural-editing package.

*** Move text up or down

=move-text= bubbles the current line or region up (=M-p=) and down (=M-n=),
preserving indentation — better than =transpose-lines=, which handles only
adjacent single lines and leaves point somewhere awkward.

#+begin_src emacs-lisp
 (use-package move-text
  :ensure t
  :bind (("M-n" . move-text-down)
         ("M-p" . move-text-up)))
#+end_src

*** Duplicate the current line or region

=C-c d= copies the current line or region below itself, point staying at the
same column. A numeric prefix makes =N= copies; a negative prefix also comments
out the original, which keeps a known-good version around while you edit the
copy. The IntelliJ =Cmd-D= reflex, ported from
https://www.emacswiki.org/emacs/CopyingWholeLines#toc12

#+begin_src emacs-lisp
     (define-key global-map (kbd "C-c d")
  (defun systemhalted/duplicate-line-or-region (&optional n)
    "Duplicate current line, or region if active.
    With argument N, make N copies.
    With negative N, comment out original line and use the absolute value."
    (interactive "*p")
    (let ((use-region (use-region-p)))
      (save-excursion
        (let ((text (if use-region        ;Get region if active, otherwise line
                        (buffer-substring (region-beginning) (region-end))
                      (prog1 (thing-at-point 'line)
                        (end-of-line)
                        (if (< 0 (forward-line 1)) ;Go to beginning of next line, or make a new one
                            (newline))))))
          (dotimes (i (abs (or n 1)))     ;Insert N times, or once if not specified
            (insert text))))
      (if use-region nil                  ;Only if we're working with a line (not a region)
        (let ((pos (- (point) (line-beginning-position)))) ;Save column
          (if (> 0 n)                             ;Comment out original with negative arg
              (comment-region (line-beginning-position) (line-end-position)))
          (forward-line 1)
          (forward-char pos))))))

#+end_src


*** Join following line or unwrap region

=C-c k= folds the next line up into the current one. With a region active it
unwraps the whole region instead, via =fill-region= with an unreachable
=fill-column=. Same intent — "make this one line" — at two scales.

#+begin_src emacs-lisp
  (define-key global-map (kbd "C-c k")
  (defun systemhalted/join-following-line ()
    "Join the following line, or unwrap the whole selected region."
    (interactive)
    (if (use-region-p)
        (let ((fill-column (point-max)))
          (fill-region (region-beginning) (region-end)))
      (join-line -1))))
#+end_src

* Environment

Import the shell environment before packages inspect local checkout paths.

** Process I/O and shell environment

=read-process-output-max= allows 1 MiB reads for language-server responses.
GUI and daemon sessions import =PATH=, =MANPATH=, =JAVA_HOME=, and the personal
checkout variables from the shell; terminal and batch sessions use what they
inherited. The shell runs =-l -i= because SDKMAN initializes in =~/.zshrc=, not
=~/.zprofile=. =C-c R= re-imports after a shell change; restart Emacs after
changing a checkout path. No disk cache, no expiry.

#+begin_src emacs-lisp
(setq read-process-output-max (* 1024 1024))

(use-package exec-path-from-shell
  :ensure t
  :demand t
  :if (or (daemonp) (memq window-system '(mac ns x pgtk)))
  :init
  (setq exec-path-from-shell-variables
        '("PATH" "MANPATH" "JAVA_HOME" "SDKMAN_EL_DIR" "TRUSTRAIL_EL_DIR"
          "WORDWISE_EL_DIR"))
  ;; SDKMAN init lives in ~/.zshrc (interactive), not ~/.zprofile (login),
  ;; so a plain login shell sees no JAVA_HOME. Use -l -i to source both.
  (setq exec-path-from-shell-arguments '("-l" "-i"))
  :config
  (exec-path-from-shell-initialize)
  :bind ("C-c R" . exec-path-from-shell-initialize))
#+end_src

* Interaction & Completion

Completion, search, buffer navigation, and help. Each package has one role.

** Savehist — persist minibuffer history

Savehist persists minibuffer history across restarts — the substrate for
Vertico's recency sort, =consult-yank-pop='s kill ring, Corfu's completion
history, and the Wordwise definition cache.

#+begin_src emacs-lisp
(use-package savehist
  :ensure nil
  :custom
  ;; `corfu-history' and `wordwise-cache' are registered here rather than from
  ;; their own sections: both packages load lazily, and savehist would drop the
  ;; variable from `history' in any session that never touched them.
  (savehist-additional-variables
   '(search-ring regexp-search-ring kill-ring corfu-history wordwise-cache))
  (history-length 200)
  :init
  (savehist-mode 1))
#+end_src

** Orderless — flexible matching style

[[https://github.com/oantolin/orderless][Orderless]] is a completion /style/, not a UI: whitespace-separated tokens
match in any order, anywhere in the candidate. Vertico and Corfu both inherit
it, because both filter through =completion-styles=.

Why the non-default values: =basic= stays in the chain for TRAMP paths, which
need strict prefix matching, and =partial-completion= is added for file names
so =/u/s/l= expands. =orderless-prefixes= splits a token on =-= / =_= and
prefix-matches each piece, so =desc-fun= finds =describe-function=.

#+begin_src emacs-lisp
(use-package orderless
  :ensure t
  :custom
  (completion-styles '(orderless basic))
  (orderless-matching-styles '(orderless-literal
                               orderless-prefixes
                               orderless-regexp))
  (completion-category-defaults nil)
  (completion-category-overrides '((file (styles basic partial-completion)))))
#+end_src

** Built-in completion defaults

Built-in switches that finish off the stack. Case-insensitive matching lets
Orderless tokens match regardless of case. =enable-recursive-minibuffers=
allows nested prompts (=M-:= inside =find-file=, Embark actions that prompt
again); =minibuffer-depth-indicate-mode= pairs with it so the prompt shows
=[2]= — without it, =C-g= looks like a full exit when it dropped one level.
=cursor-intangible-mode= keeps point out of the prompt text.

#+begin_src emacs-lisp
(use-package emacs
  :ensure nil
  :custom
  (completion-ignore-case t)
  (read-buffer-completion-ignore-case t)
  (read-file-name-completion-ignore-case t)
  (enable-recursive-minibuffers t)
  (minibuffer-prompt-properties
   '(read-only t cursor-intangible-mode t face minibuffer-prompt))
  :hook (minibuffer-setup . cursor-intangible-mode)
  :init
  (minibuffer-depth-indicate-mode 1))
#+end_src

** Vertico — minibuffer UI

** Consult — focused search and navigation commands

[[https://github.com/minad/consult][Consult]] exposes what Emacs already tracks — buffer lines, buffers, recent

| Key             | Command             |
|-----------------+---------------------|
| =C-s=           | =consult-line=      |

** Tutorial dispatcher

=C-h T= mirrors the built-in =C-h t=, but opens subtrees of /this/ file as
read-only indirect buffers: the docs live beside the code that binds them, they
render as Org, and edits to the source show up immediately because the buffer
is indirect.

Adding a tutorial needs *both* an entry in =systemhalted/tutorials= and a
matching =**= heading whose text equals the entry's cdr —
=systemhalted/tutorial= refuses a heading it cannot find. The registry uses
=defvar= + =setq= because =defvar= never overwrites a bound value: with the
list inside it, =C-c r= would keep the old registry and new tutorials would
need a restart.

*Hand-written tutorials only.* Package documentation stays out because Emacs
already dispatches it: =C-h R= completes over every Info manual, built-in /and/
package (=package.el= writes a =dir= file into each package directory);
=C-h P= describes a package; =M-x info-apropos= searches every index at once.

=q= quits. That needs saying because Org binds =q= to self-insert, which in a
read-only buffer just errors. Composing a one-key map /over/ the major mode's
map — rather than replacing it — keeps =TAB= folding and =RET= link-following.
The map is buffer-local, so the =systemhalted.org= buffer behind it is
untouched, and =quit-window= buries rather than kills, so reopening a tutorial
returns you to where you left off.

#+begin_src emacs-lisp
(defvar systemhalted/tutorials nil
  "Alist of (DISPLAY-NAME . ORG-HEADING) tutorial subtrees in systemhalted.org.")
(setq systemhalted/tutorials
      '(("Organicely"  . "Tutorial: Organicely — Org-based Second Brain")
        ("LSP and DAP" . "Tutorial: Using LSP and DAP")
        ("LaTeX"       . "Tutorial: Using LaTeX")
        ("Ghostel"     . "Tutorial: Using Ghostel")
        ("Wordwise"    . "Tutorial: Using Wordwise")))

(defun systemhalted/tutorial ()
  "Pick a tutorial subtree from systemhalted.org and view it read-only.
Mirrors `help-with-tutorial' (C-h t): a registry of named tutorials is
offered via `completing-read', and the chosen subtree is shown as a
narrowed, read-only indirect buffer over the literate config so edits
to the source remain visible without losing place.  Quit with `q'."
  (interactive)
  (let* ((choice (completing-read "Tutorial: "
                                  (mapcar #'car systemhalted/tutorials)
                                  nil t))
         (heading (cdr (assoc choice systemhalted/tutorials)))
         (buf-name (format "*Tutorial: %s*" choice)))
    (if-let* ((existing (get-buffer buf-name)))
        (pop-to-buffer existing)
      (let* ((org-file (expand-file-name "systemhalted.org" user-emacs-directory))
             (base (find-file-noselect org-file))
             (pos (with-current-buffer base
                    (org-find-exact-headline-in-buffer heading))))
        (unless pos
          (user-error "Tutorial heading %S not found in %s" heading org-file))
        (let ((indirect (make-indirect-buffer base buf-name t)))
          (with-current-buffer indirect
            (goto-char pos)
            (org-narrow-to-subtree)
            (org-fold-show-subtree)
            (goto-char (point-min))
            (read-only-mode 1)
            ;; Org binds `q' to self-insert, which only errors in a read-only
            ;; buffer.  Compose `q' -> `quit-window' over the mode's own map so
            ;; Org keeps TAB for folding and RET for links.
            (use-local-map
             (make-composed-keymap
              (let ((map (make-sparse-keymap)))
                (define-key map (kbd "q") #'quit-window)
                map)
              (current-local-map))))
          (pop-to-buffer indirect))))))
(global-set-key (kbd "C-h T") #'systemhalted/tutorial)
#+end_src

* Projects

The built-in =project.el= owns the saved project list and project commands.

** project.el — project-scoped commands

[[info:emacs#Projects][project.el]] ships with Emacs, so this is a built-in
(=:ensure nil=). Its command map lives on the standard =C-x p= prefix:

- =C-x p p= — switch project.
- =C-x p f= — find file in the current project.
- =C-x p b= — switch buffer within the project.
- =C-x p g= — regexp search across the project (=C-c s= for ripgrep via
  Consult is usually faster).
- =C-x p k= — kill the project's buffers.
- =C-x p c= — compile; =C-x p d= / =D= find-dir and dired; =C-x p v= vc-dir.
- =C-x p m= — Ghostel terminal rooted at the project (added in the Terminal
  section).

=C-x p C-h= lists the rest.

*Why not Projectile.* Most of this config was already on =project.el= before
the switch: Consult resolves =consult-buffer='s project source and
=consult-ripgrep='s root through =consult-project-function=, which calls
=project-current= — and Ghostel registers itself in =project-prefix-map= and
=project-switch-commands=. Only the =C-c p= keymap and Dashboard's backend
were Projectile's, so keeping it meant two project systems disagreeing about
what the current project is. Dropping it also frees =C-c p=, which used to
constrain every other binding in this file.

Two Projectile behaviours are deliberately given up: recency ordering of
=project-find-file= candidates (=projectile-sort-order 'recentf=, which
=project.el= has no equivalent for — Orderless narrowing covers it), and
=.projectile= marker files. Project /switching/ still favours recent
projects: =project-remember-project= pushes to the front of the list and
=project-prompt-project-dir= passes the known roots as completion history,
which Vertico's history-aware sort picks up.

Roots come from the VC backend — a =.git= directory and friends. For a
project that is not under version control, or a subdirectory of a monorepo
that should be its own root, add its build file to
=project-vc-extra-root-markers= (="pom.xml"=, ="Cargo.toml"=,
="package.json"=, …). It is left empty here so a marker file deep inside a
git repository never silently re-roots a buffer.

*Discovery.* Nothing scans at startup — =project.el= only ever reads
=project-list-file=. Run =M-x systemhalted/discover-projects= after adding a
repository under =systemhalted/projects-root= (default =~/Work=); it registers
every project directly below that root, then refreshes an open Dashboard
without selecting it.

It walks that one level itself rather than calling
=project-remember-projects-under=, whose non-recursive behaviour is *not the
same across supported Emacs versions*: on Emacs 30 it tests DIR's children,
but on Emacs 29 the queue starts at DIR itself and only descends when RECURSIVE
is set — so the same call finds nothing on 29. The loop below also skips =.=
and =..=, and requires the project root to /be/ the child directory, so a
=~/Work= that happens to sit inside a repository does not register that
ancestor once per child. For a nested layout, Emacs's own
=M-x project-remember-projects-under= with a prefix argument still works.

#+begin_src emacs-lisp
  (defvar systemhalted/projects-root "~/Work"
    "Root directory under which projects are discovered.")

  (use-package project
    :ensure nil
    :custom
    ;; Empty on purpose: with markers set, a package.json inside a monorepo
    ;; would re-root buffers below it.  Add one when a real non-VC project
    ;; turns up.
    (project-vc-extra-root-markers nil))

  ;; C-x p is project.el's own prefix, so C-c p is free now.  Unbinding it
  ;; (rather than just not binding it) clears Projectile's keymap from a
  ;; long-running session on C-c r.
  (global-unset-key (kbd "C-c p"))

  (defun systemhalted/discover-projects (&optional root)
    "Register every project directly under ROOT (`systemhalted/projects-root').
Returns the number registered.  Reads the root at call time, so changing
`systemhalted/projects-root' needs no restart.

Deliberately not `project-remember-projects-under': its non-recursive pass
tests DIR's children on Emacs 30 but DIR itself on Emacs 29, so the same call
means different things on the versions this config supports."
    (interactive)
    (let ((root (expand-file-name (or root systemhalted/projects-root)))
          (count 0))
      (unless (file-directory-p root)
        (user-error "Project root does not exist: %s" root))
      (dolist (dir (directory-files root t directory-files-no-dot-files-regexp))
        (when-let* (((file-directory-p dir))
                    (pr (project-current nil dir))
                    ;; Register the child, never an ancestor repository that
                    ;; happens to contain ROOT.
                    ((equal (expand-file-name (project-root pr))
                            (file-name-as-directory dir))))
          (project-remember-project pr)
          (setq count (1+ count))))
      (when (get-buffer dashboard-buffer-name)
        (save-selected-window
          (dashboard-insert-startupify-lists t)))
      (message "%d project%s under %s" count (if (= count 1) "" "s") root)
      count))
#+end_src

* Development & Languages

Shared diagnostics, snippets, LSP, and debugging come before language settings. SDKMAN lives here because Java depends on it.

** compile — multiple compilation buffers

All compilation commands share one =*compilation*= buffer by default, so a
long-lived =mvn spring-boot:run= blocks the next =mvn test=. Naming each buffer
after its command lets different commands run in parallel while the /same/
command reuses its buffer — no =*compilation*<2>= pile-up, and =next-error=
keeps pointing at the live one.

One indirection is needed: the name function runs /before/ the buffer exists,
so buffer-local =compilation-arguments= is still nil. An =:around= advice on
=compilation-start= parks the command in a dynamic variable for the duration of
the call.

#+begin_src emacs-lisp
(use-package compile
  :ensure nil
  :defer t
  :custom
  (compilation-scroll-output t)
  :config
  (defvar systemhalted/compilation--command nil
    "Command of the compilation being started, for buffer naming.
Bound around `compilation-start' because the name function runs before
the compilation buffer (and its local `compilation-arguments') exists.")

  (define-advice compilation-start
      (:around (orig command &rest args) systemhalted/capture-command)
    "Expose COMMAND to `systemhalted/compilation-buffer-name'."
    (let ((systemhalted/compilation--command command))
      (apply orig command args)))

  (defun systemhalted/compilation-buffer-name (mode)
    "Name the compilation buffer after the command being run.
MODE is the major-mode name passed by `compilation-start'.  The same
command reuses its buffer; different commands run in parallel in
buffers of their own."
    (let* ((cmd (or systemhalted/compilation--command "compile"))
           ;; Truncate long commands for readability
           (short-cmd (if (> (length cmd) 40)
                          (concat (substring cmd 0 37) "...")
                        cmd)))
      (format "*%s: %s*" mode short-cmd)))
  (setq compilation-buffer-name-function #'systemhalted/compilation-buffer-name))
#+end_src

** LSP-mode — protocol, completion, memory tuning

The protocol layer. Java attaches through
=systemhalted/lsp-deferred-unless-excluded=; Lua, JS/TS, web, CSS, and Rust
through plain =lsp-deferred=. Three reasons for the non-default settings:

*Memory bounds.* A Java session once pushed Emacs past 50 GiB resident. JDT LS
itself is capped by =lsp-java-vmargs=, so the growth was Emacs retaining
protocol messages, watches, and completion metadata. Hence: no Emacs-side file
watchers (JDT LS has its own), a tiny IO log, capped in-memory protocol
history, and =lsp-keep-workspace-alive nil= so killing the last buffer releases
the server immediately.

*The =:none= gotcha.* =lsp-completion-provider= is =:none=, *not* =:capf=,
even though completion is wanted. =lsp-completion-mode= registers
=lsp-completion-at-point= on =completion-at-point-functions= regardless of this
setting; the option only controls whether =lsp-mode= tries to auto-enable
=company-mode=. With Corfu and no company installed, =:capf= still takes the
company branch and warns "Unable to autoconfigure company-mode" once per
buffer. =:none= skips it and leaves the capf wired up.

*Quiet by default.* Symbol highlighting, breadcrumbs, modeline code actions,
on-type formatting, and completion detail/kind are all off. Each is available
on demand from the =C-c l= bindings below.

#+begin_src emacs-lisp
(use-package lsp-mode
  :ensure t
  :commands
  (lsp lsp-deferred)
  :hook
  ((java-mode . systemhalted/lsp-deferred-unless-excluded)
   ((js-mode rjsx-mode typescript-mode web-mode css-mode lua-mode rustic-mode) . lsp-deferred))
  :bind
  (:map lsp-mode-map
        ("C-c C-f" . lsp-format-buffer)
        ("C-c l h h" . lsp-describe-thing-at-point)
        ("C-c l i" . corfu-popupinfo-toggle)
        ("C-c l H" . lsp-toggle-symbol-highlight)
        ("C-c l F" . lsp-toggle-on-type-formatting)
        ("C-c l R" . lsp-workspace-restart)
        ("C-c l j u" . lsp-java-update-project-configuration))
  :custom
  (lsp-keymap-prefix "C-c l")
  ;; :none is the Corfu-correct value despite the name. lsp-completion-mode
  ;; registers `lsp-completion-at-point' on `completion-at-point-functions'
  ;; unconditionally; the provider setting only controls whether lsp-mode
  ;; tries to auto-enable company-mode. With Corfu we don't have company,
  ;; so :capf still takes the company branch and warns "Unable to
  ;; autoconfigure company-mode." :none skips that branch entirely while
  ;; leaving capf wired up — which is what Corfu consumes.
  (lsp-completion-provider :none)
  (lsp-completion-show-detail nil)
  (lsp-completion-show-kind nil)
  (lsp-enable-file-watchers nil)
  (lsp-enable-symbol-highlighting nil)
  (lsp-enable-on-type-formatting nil)
  (lsp-idle-delay 1.0)
  (lsp-io-messages-max 200)
  (lsp-keep-workspace-alive nil)
  (lsp-log-io nil)
  (lsp-log-max 2000)
  (lsp-file-watch-threshold 2000)
  (lsp-headerline-breadcrumb-enable nil)
  (lsp-enable-snippet t)
  (lsp-modeline-code-actions-enable nil)
  (lsp-response-timeout 30))

** LSP-UI — sideline and doc tweaks

Almost everything here is off: the sideline and the perpetual docs popup were
the worst offenders for flicker and CPU churn in long Java sessions. Hover docs
stay available on =C-c l h h=, and =lsp-ui-doc-include-signature= keeps the

** LSP-Java — JDT LS configuration

Eclipse JDT LS configuration.

- *Lombok agent.* Lombok rewrites the AST through bytecode manipulation, not
  annotation processing, so JDT LS only sees =.builder()= and friends if
  Lombok is loaded as a JVM agent. VS Code bundles the JAR; =lsp-java= does
  not, so =-javaagent:= points at the Maven-cached one.
  =systemhalted/lombok-jar-path= picks the newest main =lombok-VERSION.jar=
  by semantic version, ignoring sources/javadoc artifacts and ranking a
  non-numeric directory (=edge-SNAPSHOT=) below every release instead of
  erroring. Missing? Run =mvn dependency:resolve= in any Lombok project. The
  agent is inert where Lombok is unused.
- =lsp-java-completion-guess-method-arguments nil= — the generated =arg0=,
  =arg1= placeholders are always wrong, and deleting them costs more than
  typing the real names.
- =...update-build-configuration "interactive"= — silent re-sync on a POM
  change churns the workspace and steals focus. =C-c l j u= does it on demand.
- Server binaries and workspace caches go under =eclipse.jdt.ls/= inside
  =user-emacs-directory=, which =.gitignore= already covers.

#+begin_src emacs-lisp
(defun systemhalted/lombok--jar-version (jar)
  "Return the Maven version directory containing Lombok JAR."
  (file-name-nondirectory
   (directory-file-name (file-name-directory jar))))

(defun systemhalted/lombok--jar-version-list (jar)
  "Return Lombok JAR's parsed version, or nil for a non-numeric one.
Maven version directories like \"edge-SNAPSHOT\" don't parse as versions;
they rank below every numeric release instead of signaling."
  (condition-case nil
      (version-to-list (systemhalted/lombok--jar-version jar))
    (error nil)))

(defun systemhalted/lombok-jar-path ()
  "Return the path to the newest main Lombok JAR in the Maven cache, or nil."
  (let ((jars
         (seq-filter
          (lambda (jar)
            (let ((version (systemhalted/lombok--jar-version jar)))
              (string=
               (file-name-nondirectory jar)
               (format "lombok-%s.jar" version))))
          (file-expand-wildcards
           (expand-file-name
            "~/.m2/repository/org/projectlombok/lombok/*/lombok-*.jar")))))
    (car
     (sort jars
           (lambda (a b)
             (let ((va (systemhalted/lombok--jar-version-list a))
                   (vb (systemhalted/lombok--jar-version-list b)))
               (cond ((and va vb) (version-list-< vb va))
                     (va t)
                     (t nil))))))))
#+end_src

** DAP-mode — Java debugging through JDT LS

=dap-mode= rides the JDT LS that =lsp-java= already installs — no extra
server. =C-c l d= opens the DAP hydra. =dap-auto-configure-features= keeps the
four default panes; REPL, expressions, and the breakpoint list stay available
but off.

Two advices work around upstream:

*Timeout.* =dap-java--populate-default-args= resolves main class and classpath
through synchronous JDT LS commands, and a cold Maven import can exceed the
30 s interactive timeout while the server is perfectly healthy. The =:around=
advice raises it to 60 s for that call.

*JPMS module paths.* For a module declaring itself in =module-info.java=,
=vscode.java.resolveMainClass= returns a module-qualified class
(=my.api/com.example.Test=). Upstream =dap-java--populate-launch-args= calls
=vscode.java.resolveClasspath=, which returns =[modulePaths classPaths]=, but
keeps only =classPaths= and pins =:modulePaths= to an empty vector — so the
class launches in classpath mode, the JVM rewrites =/= to =.=, and the jdwp
handshake fails with =ClassNotFoundException=. The =:filter-return= advice
re-resolves and forces =:modulePaths= when it is non-empty. It must use
=plist-put=: the pre-set empty vector is non-nil, so =dap--put-if-absent=
would never replace it. Non-modular projects come back empty and are untouched.
Use the plain *Java Run Configuration* template — the *compile/attach* variant
hand-rolls its own =java -cp= command and is not module-aware.

Upstream bug: [[https://github.com/emacs-lsp/lsp-java/issues/511][lsp-java#511]]. Drop both advices when it is fixed.

#+begin_src emacs-lisp
(defun systemhalted/with-longer-dap-java-timeout (orig-fun &rest args)
  "Call ORIG-FUN with a longer timeout for DAP Java launch metadata."
  ;; `dap-java-debug' resolves main class, classpath, and debug-server
  ;; metadata through synchronous JDT LS commands. Cold Maven imports can
  ;; exceed the normal interactive LSP timeout without implying server failure.
  (let ((lsp-response-timeout 60))
    (apply orig-fun args)))

(defun systemhalted/dap-java-add-module-paths (conf)
  "Populate :modulePaths in CONF for JPMS-modular Java launch configs.

`dap-java--populate-launch-args' resolves the classpath via
`vscode.java.resolveClasspath', which returns a two-element sequence
[MODULE-PATHS CLASS-PATHS].  Upstream keeps only CLASS-PATHS (cl-second)
and forces :modulePaths to an empty vector, so a module declared in a
`module-info.java' is launched in classpath mode with a module-qualified
main class (e.g. \"kisoku.api/in.systemhalted.kisoku.api.Test\").  The JVM
then rewrites \"/\" to \".\" and fails with ClassNotFoundException before
the jdwp handshake.

This filter re-resolves the classpath, and when MODULE-PATHS (cl-first)
is non-empty sets :modulePaths forcefully (plist-put, not
`dap--put-if-absent', because the template's pre-set empty vector is
non-nil and would never be overridden).  The bundled java-debug adapter
then assembles `--module-path ... -m module/Class' on its own.  For
non-modular projects MODULE-PATHS is empty and CONF is returned
unchanged.

Workaround for upstream emacs-lsp/lsp-java: dap-java--populate-launch-args
discards resolveClasspath's module paths (keeps only cl-second).  Remove
this advice once that is fixed upstream.  See
https://github.com/emacs-lsp/lsp-java/issues/511."
  (-let [(&plist :mainClass main-class :projectName project-name) conf]
    (when (and main-class project-name)
      (let* ((resolved (with-lsp-workspace (lsp-find-workspace 'jdtls)
                         (lsp-send-execute-command
                          "vscode.java.resolveClasspath"
                          (vector main-class project-name))))
             (module-paths (and resolved (elt resolved 0))))
        (when (and module-paths (not (seq-empty-p module-paths)))
          (setq conf (plist-put conf :modulePaths module-paths))))))
  conf)

(use-package dap-mode
  :ensure t
  :after lsp-java
  :bind
  (:map lsp-mode-map
        ("C-c l d" . dap-hydra))
  :custom
  (dap-auto-configure-features '(sessions locals controls tooltip))
  :config
  (require 'dap-java)
  ;; `advice-add' drops an identical existing advice before adding, so these
  ;; stay single-applied across a C-c r reload with no explicit removal.
  (advice-add 'dap-java--populate-default-args
              :around
              #'systemhalted/with-longer-dap-java-timeout)
  (advice-add 'dap-java--populate-launch-args
              :filter-return
              #'systemhalted/dap-java-add-module-paths))
#+end_src

** Rust — rustic and rust-analyzer

=rustic= is a cargo-integrated superset of =rust-mode=: =C-c C-c= cargo
bindings, colorized compilation, rustfmt-on-save. Language intelligence is
=lsp-mode='s built-in =rust-analyzer= client — no separate lsp package.

Rustic's own lsp auto-setup is disabled (=rustic-lsp-client nil=) and
=rustic-mode= rides the shared =lsp-mode= hook like every other language. That
keeps all lsp-managed modes in one list and guarantees one =rust-analyzer= per
workspace instead of one from rustic plus one from the hook.

=lsp-rust-analyzer-cargo-watch-command "clippy"= runs clippy rather than plain
=cargo check=, so its idiomatic-Rust lints land in Flycheck next to type
errors.

The toolchain must be on the =PATH= =exec-path-from-shell= imports. =rustup= is
the portable install:

#+begin_src sh
# Portable: rustup installs rustc + cargo, then add the analyzer component.
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
rustup component add rust-analyzer   # rustfmt + clippy ship in the default profile
#+end_src

Distro packages also work: macOS =sudo port install rust rust-analyzer=
(MacPorts) or =brew install rustup rust-analyzer= then =rustup-init=
(Homebrew); Fedora =dnf install rust cargo rust-analyzer rustfmt clippy=;
Ubuntu =apt install rustup= then =rustup component add rust-analyzer=
(Ubuntu's standalone =rust= packages lag — rustup is preferred).

#+begin_src emacs-lisp
(use-package rustic
  :ensure t
  :mode ("\\.rs\\'" . rustic-mode)
  :custom
  ;; Don't let rustic auto-start lsp; rustic-mode is hooked via lsp-mode's own
  ;; :hook list like every other language, so all lsp-managed modes live in one
  ;; place — and only one rust-analyzer starts per workspace.
  (rustic-lsp-client nil)
  ;; The format-on-save knob is `rustic-format-trigger', set to the symbol
  ;; 'on-save (there is no `rustic-format-on-save'); rustfmt runs over the
  ;; buffer just before each save via `rustic-format-on-save-method'.
  (rustic-format-trigger 'on-save)
  ;; rust-analyzer runs clippy (not plain cargo check) so its richer lints
  ;; surface in Flycheck — valuable while learning idiomatic Rust. We set this
  ;; directly because rustic's own lsp setup (which would force it back to
  ;; "check") is disabled via `rustic-lsp-client nil' above.
  (lsp-rust-analyzer-cargo-watch-command "clippy"))
#+end_src

** Shell scripts and dotfiles

Shell scripts and shell dotfiles use the built-in =sh-mode=. =lsp-mode=
ships a client for =bash-language-server= (no wrapper package needed) and
Flycheck routes diagnostics through =shellcheck= when it's on =PATH=.
Both are external; install before opening a shell file:

#+begin_src sh
# bash-language-server (npm, all platforms):
npm install -g bash-language-server

# shellcheck:
# macOS, MacPorts:   sudo port install shellcheck
# macOS, Homebrew:   brew install shellcheck
# Fedora:            sudo dnf install ShellCheck
# Ubuntu / Debian:   sudo apt install shellcheck
#+end_src

=sh-mode= already handles ordinary =.sh= files via shebang and =$SHELL=, so
this only teaches it the extensionless zsh dotfiles, where the name is the only
hint to the dialect. =systemhalted/sh-pick-shell= matches a tight list of known
names and sets =zsh= or =bash= accordingly. Ambiguous names — =.profile=,
=foo.zshrc= — are left alone so the built-in detection still gets a chance.

#+begin_src emacs-lisp
(use-package sh-script
  :ensure nil
  :mode (("\\.zshrc\\'"    . sh-mode)
         ("\\.zshenv\\'"   . sh-mode)
         ("\\.zprofile\\'" . sh-mode)
         ("\\.zlogin\\'"   . sh-mode)
         ("\\.zlogout\\'"  . sh-mode))
  :hook
  (sh-mode . systemhalted/sh-pick-shell)
  (sh-mode . lsp-deferred)
  :config
  (defun systemhalted/sh-pick-shell ()
    "Set `sh-shell' for known shell dotfiles; leave the default alone otherwise.
Matching only well-known names avoids clobbering `sh-mode''s own detection
\(shebang, `$SHELL') for ambiguous files like `.profile' or `foo.zshrc'."
    (when buffer-file-name
      (let ((name (file-name-nondirectory buffer-file-name)))
        (cond
         ((or (string-match-p "\\`\\.?z\\(?:shrc\\|shenv\\|profile\\|login\\|logout\\)\\'" name)
              (string-match-p "\\.zsh\\'" name))
          (sh-set-shell "zsh" nil nil))
         ((string-match-p "\\`\\.?bash\\(?:rc\\|_profile\\|_login\\|_logout\\|_aliases\\)\\'" name)
          (sh-set-shell "bash" nil nil)))))))
#+end_src

** Tutorial: Using LSP and DAP

Documentation only — nothing here tangles.

*** Everyday code intelligence

LSP attaches automatically in =java-mode=, =python-mode=, =lua-mode=,
=js-mode=, =rjsx-mode=, =typescript-mode=, =web-mode=, =css-mode=,
=rustic-mode=, and =sh-mode=. The mode line shows =LSP[<server>]= once the
server is up; if it never appears, check =*lsp-log*=.

=M-.= jumps to a definition and =M-,= comes back — =lsp-mode= installs an
=xref= backend, so the standard keys route through the language server.

| Keys            | Command                                 |
|-----------------+-----------------------------------------|
| =C-c l g g=     | =lsp-find-definition=                   |
| =C-c l g r=     | =lsp-find-references=                   |
| =C-c l g i=     | =lsp-find-implementation=               |
| =C-c l g h=     | =lsp-treemacs-call-hierarchy= (=C-u= for outgoing) |
| =C-c l r r=     | =lsp-rename=                            |
| =C-c l r o=     | =lsp-organize-imports=                  |
| =C-c l a a=     | =lsp-execute-code-action=               |
| =C-c l h h=     | =lsp-describe-thing-at-point= (hover docs) |
| =C-c l i=       | =corfu-popupinfo-toggle=                |
| =C-c l H= / =F= | toggle symbol highlight / on-type formatting |
| =C-c l R=       | =lsp-workspace-restart=                 |
| =C-c l j u=     | =lsp-java-update-project-configuration= |
| =C-c C-f=       | =lsp-format-buffer=                     |

Hold =C-c l= and which-key shows the rest. Diagnostics are Flycheck's
(=C-c ! n= / =C-c ! p= / =C-c ! l=), completion is Corfu's after three
characters, snippets expand on =TAB=. Hover docs and completion docs are both
manual by design.

The two recovery commands worth memorizing: =C-c l R= restarts the server for
this project, and =M-x lsp-describe-session= shows what is running where.

For Java, wait for =LSP[jdtls]= before invoking refactors or debugging — code
actions and =dap-java-debug-*= need the project model. Build-config updates are
interactive: after changing =pom.xml= or =build.gradle=, run =C-c l j u=.

*** Per-language notes

*JS / TS / TSX.* Served by =ts-ls=. On the first file from a new project
=lsp-mode= prompts for the root — answer =i= to import the suggested one
(=M-x lsp-workspace-folders-remove= undoes a wrong choice). Auto-import works
two ways: accept a Corfu candidate from another module and =ts-ls= attaches the
=import= as an additional edit; or put point on a "Cannot find name" error and
=C-c l a a= → /Add import from .../, which is the route for pasted code. The
completion popup hides the detail column, so use =C-c l i= when it matters
which module a candidate comes from. =C-c l r o= sorts imports and drops unused
ones — manual by design, nothing runs it on save. Compiler settings come from
the nearest =tsconfig.json=, resolved by =tsserver= itself.

*Lua.* =lua-language-server= with =luacheck= chained behind it, so unused
locals and style findings share the error list with server diagnostics.
Formatting is =C-c C-f=. =M-x run-lua= uses the same interpreter as Org Babel.

*Rust.* =rust-analyzer=, with diagnostics from *clippy* rather than =cargo
check=. rustfmt runs on save. The most useful assist is generating code that
does not exist yet: call a method you have not written, put point on the call,
=C-c l a a= → /Generate a method/. On an =impl Trait for T= header the same

*** Debugging Java with DAP

DAP is not enabled for every LSP buffer — that keeps normal editing lighter.

=r= restart frame, =q= disconnect. Also worth knowing:
=dap-ui-inspect-thing-at-point=, =dap-breakpoint-condition= (a Java boolean

*** Common failure modes

- /JDT LS does not start./ Check =*lsp-log*=. If =eclipse.jdt.ls/server/= is
  empty, run =M-x lsp-install-server RET jdtls=.
- /=dap-java-debug-*= finds no main class or test./ The project has not
  finished importing. Wait for =LSP[jdtls]= and retry.
- /Stale state after a dependency change./ =C-c l R=. If the build file
  changed, =C-c l j u= first.
- /Lombok annotations show as errors./ The agent is missing from
  =lsp-java-vmargs=. Check =~/.m2/repository/org/projectlombok/lombok/=; if
  empty, run =mvn dependency:resolve=, then =C-c l R=.
- /External file changes do not appear./ Emacs-side watchers are off to keep
  memory bounded. =C-c l R= after large external changes.
- /Memory still grows./ Keep =lsp-log-io= off and close old project buffers so
  =lsp-keep-workspace-alive nil= can shut idle servers down. The next fix is
  =LSP_USE_PLISTS=true= before =lsp-mode= loads, plus a reinstall.
- /No completions or diagnostics in a shell, JS/TS, or Lua buffer./ The
  language server is not installed — =*lsp-log*= names it (=bash-ls=, =ts-ls=,
  =lua-language-server=). Install per the shell blocks above and reopen the
  buffer. For TypeScript, a project's own =node_modules/.bin/tsserver= does not
  count: that is the raw server, not the =ts-ls= wrapper. Flycheck separately
  reports =shellcheck= or =luacheck= when the linter is what is missing.
- /ts-ls nags about unreachable code or unread declarations./ Those are
  =tsserver= hints. Add the numeric code from the Flycheck message to
  =systemhalted/lsp-ts-ignored-diagnostic-codes= (Web editing section), =C-c r=,
  then =C-c l R=. =lsp-typescript-suggestion-actions-enabled= does /not/
  silence them — =typescript-language-server= ignores that VS Code setting.

** Magit — Git through a status buffer

=C-x g= opens Magit status: =s= stages, =u= unstages, =c c= commits, =b b=
switches branches, =l l= shows the log.

Commits and rebases started inside Magit open their edit buffer here and finish
with =C-c C-c= — the shell's editor never appears. For Git run from an
*external terminal*, the point is to reuse this Emacs rather than spawn a
throwaway one you would have to quit to release =git=. That is what the
always-on =server= is for:

#+begin_example
git config --global core.editor    "emacsclient -t -a ''"
git config --global sequence.editor "emacsclient -t -a ''"
#+end_example

=-t= opens a frame in the current terminal, =-a ''= starts a daemon if none is
reachable, =C-c C-c= finishes and =C-c C-k= aborts without killing Emacs. The
single-key rebase commands and the finish key come from =with-editor= and
=git-rebase=, which arrive as Magit dependencies.

Those three libraries load eagerly at startup rather than on an idle timer, so
library loading stays out of the first client handoff. Emacs handles the input
normally — no advice on =undefined=, no key replay.
=test/daemon-editor-test.sh= exercises finish and abort at several points
during a delayed handoff.

  :demand t
  :bind ("C-x g" . magit-status)
  :config
  (require 'git-rebase))

* Org / Knowledge

Organicely is for notes. Tasks and calendar events remain outside Org.

** Tutorial: Organicely — Org-based Second Brain

One rule decides where everything goes:

#+begin_example
Has a "done" state -> Apple Reminders
Has a date         -> Apple Calendar
Everything else    -> org
#+end_example

"Buy milk" is a Reminder; "Why CRDTs converge" is a note. When in doubt, ask
whether the item can ever be /finished/ — if yes, it does not belong here.

*The structure.* =~/organicely/= is a directory tree; every note is its own
=.org= file with a =#+TITLE:= and prose under it. The numbered areas mirror the
Apple Notes folders, and each holds section subdirectories:

#+begin_example
00-inbox/      unfiled captures (emptied during the weekly sweep)
10-work/       work notes
20-personal/   career/ home/ health/ family/ finances/ purchases/ recommendations/
30-learning/   ai-sessions/ articles/ books/ podcasts/ courses/ videos/ subjects/
40-writing/    concepts/ ideas/ drafts/ articles/ podcasts/ poetry/ stories/ books/ published/
50-journal/    daily/ (one file per day)   old/ (migrated entries)
60-ideas/      apps-and-tools/ business/ research-questions/
99-archive/    done thinking, kept searchable
#+end_example

Filenames are kebab-case slugs of the title. Sections are just directories, so
a new one appears the moment you file into it.

*Capture.* =C-c c= (=c= Note) asks where, then a title:

#+begin_example
Capture to:  Inbox              -> 00-inbox/<timestamp>.org  (title optional; file it later)
             20-personal/health -> 20-personal/health/<title>.org
             10-work/meetings   (type a new area/section to create it on the fly)
#+end_example

Pick =Inbox= when deciding would interrupt the thought, an area/section to file
it straight away. Either way you get a fresh file with a header, left open to
write.

*Journaling.* A writing session, not a capture, so it keeps its own key. =C-c J=
opens today's =50-journal/daily/YYYY-MM-DD.org=, creating it if needed, alone in
the frame with book view on. =C-c B= turns the view off when done.

*Source notes.* =C-c c s= launched from a heading in another Org file files the
note in =00-inbox/sources.org= under a heading dedicated to that source, keyed
by =:SOURCE_ID:= — so every note from one source stays together even after it
is renamed. From a non-Org buffer it falls back to a flat =* Inbox= heading.
The body carries a =%a= backlink, so =C-c C-o= returns to what you were
reading.

*The weekly sweep.* Half an hour, once or twice a week:

1. Move anything in the Apple Notes Inbox into org (capture or paste).
2. Open each file in =00-inbox/= and refile it with =C-c C-w= — this /moves the
   file/ (and its attachments) into a chosen =area/section= directory, completed
   through vertico. Filing into =30-learning/articles= is a few keystrokes; type
   a directory that does not exist yet to create it.
3. Notes about finished thinking move to =99-archive/=.

The inbox should be empty when the sweep ends. The system stays trustworthy
because of this ritual, not because of any enforcement.

*Retrieval.* =C-c n= ripgreps =~/organicely/= only; with one file per note it
drops you straight into it. (=C-c s= is the general search that asks for a
directory.) Inside a note, =C-c l= stores a link and =C-c C-l= inserts it.

*The soft warning.* Saving a file under =~/organicely/= that holds a =TODO= /
=IN-PROGRESS= / =DONE= heading or a =SCHEDULED:= / =DEADLINE:= line prints a
reminder that it belongs in Reminders. The save always succeeds — a nudge, not
a guard.

*Attachments.* A note's files live beside it in =<note>-attachments/=; =C-c C-w=
carries them along when you refile.

Org Babel loads Emacs Lisp, Java, Python, Lua, and shell. =C-c j= adds Jupyter
for the session when a file needs notebook-style execution.

** Path helpers and directory vocabulary

The vocabulary the rest of the Org setup speaks.

*Paths.* =systemhalted/org-file= resolves a relative name (including an
=area/section= subpath) against =org-directory=, so nothing else hard-codes
=~/organicely/=. =systemhalted/org-buffer-file-p= compares through
=file-truename=, so a symlink into the tree behaves like the real thing.

*Structure.* =systemhalted/org-area-dirs= names the eight numbered areas;
=systemhalted/org-area-sections= records the subdirectories seeded under each
(=10-work= and =99-archive= stay flat). Sections are only directories — new
ones appear on demand at capture or refile.
=systemhalted/org-section-dirs= lists every =area= and =area/section= as
completion candidates, skipping attachment folders.

*Naming.* =systemhalted/org-slug= kebab-cases a title (Unicode letters kept);
=systemhalted/org-unique-file= adds a numeric suffix so two notes never
collide.

*The one rule.* =systemhalted/org-done-state-regexp= is the single definition
of "task-shaped": a =TODO= / =IN-PROGRESS= / =DONE= heading, or a =SCHEDULED:=
/ =DEADLINE:= line. Those belong in Reminders.

*Capture and refile.* =systemhalted/org-capture-file= (the =C-c c= target)
prompts for a destination and a title, then creates the file with its header.
=systemhalted/refile-note= (=C-c C-w=) is the weekly-sweep counterpart: it moves
the note's file and its =-attachments= directory into a chosen =area/section=,
rolling back a partial move before signalling. Both validate the destination as
a configured area plus at most one section level, so empty, absolute, hidden,
and escaping paths never leave Organicely — a new /area/ is a deliberate edit
to =systemhalted/org-area-dirs=, never a capture-time typo.

=systemhalted/org-goto-or-create-heading= puts point on a named top-level
heading, creating it when missing; the source-aware capture below uses it.

*Journal.* =C-c J= (=systemhalted/journal=) opens today's
=50-journal/daily/YYYY-MM-DD.org=, creating it with a title like
=5th June 2026, Friday=, alone in the frame with book view on. =C-c B= toggles
the view off; =C-x C-s= saves.

#+begin_src emacs-lisp
(defun systemhalted/org-file (file)
  "Return FILE expanded inside `org-directory'."
  (expand-file-name file org-directory))

(defun systemhalted/org-buffer-file-p (file)
  "Return non-nil when the current buffer visits FILE in `org-directory'."
  (and buffer-file-name
       (string= (file-truename buffer-file-name)
                (file-truename (systemhalted/org-file file)))))

(defconst systemhalted/org-area-dirs
  '("00-inbox" "10-work" "20-personal" "30-learning"
    "40-writing" "50-journal" "60-ideas" "99-archive")
  "The numbered area directories that make up Organicely.
Each note is its own file inside one of these (optionally in a section subdir).")

(defconst systemhalted/org-area-sections
  '(("20-personal" . ("career" "home" "health" "family" "finances"
                      "purchases" "recommendations"))
    ("30-learning" . ("ai-sessions" "articles" "books" "podcasts"
                      "courses" "videos" "subjects"))
    ("40-writing"  . ("concepts" "ideas" "drafts" "articles" "podcasts"
                      "poetry" "stories" "books" "published"))
    ("50-journal"  . ("daily" "old"))
    ("60-ideas"    . ("apps-and-tools" "business" "research-questions")))
  "Section subdirectories seeded under each area; unlisted areas stay flat.
Sections are just directories — new ones are created on demand at capture/refile.")

(defconst systemhalted/org-done-state-regexp
  (concat "^\\*+ \\(?:TODO\\|IN-PROGRESS\\|DONE\\)\\(?:[ \t]\\|$\\)"
          "\\|^[ \t]*\\(?:SCHEDULED\\|DEADLINE\\):")
  "Matches task headings or planning lines — things that belong in Reminders.")

(defun systemhalted/org-goto-or-create-heading (heading)
  "Move point onto top-level HEADING, creating it when needed.
Leaves point on the heading line itself so `org-capture' treats it as
the parent entry and appends the capture to the end of its subtree."
  (goto-char (point-min))
  (if (re-search-forward
       (format "^\\* %s[ \t]*$" (regexp-quote heading)) nil t)
      (beginning-of-line)
    (goto-char (point-max))
    (unless (bolp)
      (insert "\n"))
    (unless (bobp)
      (insert "\n"))
    (insert "* " heading "\n")
    (forward-line -1)))

(defun systemhalted/org-slug (s)
  "Kebab-case slug from S: lowercase, non-alphanumeric runs -> hyphen; keeps Unicode letters."
  (let ((x (downcase (string-trim s))))
    (setq x (replace-regexp-in-string "[^[:alnum:]]+" "-" x))
    (setq x (replace-regexp-in-string "-\\{2,\\}" "-" x))
    (setq x (string-trim x "-+" "-+"))
    (if (string-empty-p x) "note" x)))

(defun systemhalted/org-unique-file (dir stem)
  "Return a non-colliding DIR/STEM.org path, adding -N on collision.
A matching attachment directory also counts as a collision."
  (let ((path (expand-file-name (concat stem ".org") dir)) (i 2))
    (while (or (file-exists-p path)
               (file-exists-p
                (concat (file-name-sans-extension path) "-attachments")))
      (setq path (expand-file-name (format "%s-%d.org" stem i) dir))
      (setq i (1+ i)))
    path))

(defun systemhalted/org--validate-destination (relative)
  "Return valid Organicely destination RELATIVE, or signal `user-error'.
Destinations are a configured area, or one non-hidden section beneath it.
A directory-style trailing slash is normalized away in the returned value."
  (setq relative (directory-file-name relative))
  (let ((parts (split-string relative "/" nil)))
    (unless
        (and (not (file-name-absolute-p relative))
             (memq (length parts) '(1 2))
             (member (car parts) systemhalted/org-area-dirs)
             (seq-every-p
              (lambda (part)
                (and (not (string-empty-p (string-trim part)))
                     (not (string-prefix-p "." part))
                     (not (string-match-p "\\\\" part))
                     (not (string-suffix-p "-attachments" part))
                     (not (string-suffix-p "(Attachments)" part))))
              parts))
      (user-error
       "Choose a configured area or one area/section under Organicely"))
    relative))

(defun systemhalted/org-section-dirs ()
  "Relative \"area\" and \"area/section\" directories under `org-directory'.
These are the completion candidates for capture and refile."
  (let (dirs)
    (dolist (area systemhalted/org-area-dirs)
      (push area dirs)
      (let ((adir (systemhalted/org-file area)))
        (when (file-directory-p adir)
          (dolist (sub (directory-files adir nil "\\`[^.]"))
            (when (and (file-directory-p (expand-file-name sub adir))
                       (not (string-suffix-p "-attachments" sub))
                       (not (string-suffix-p "(Attachments)" sub)))
              (push (concat area "/" sub) dirs))))))
    (nreverse dirs)))

(defun systemhalted/org-capture-file ()
  "Capture target: create a fresh note file and switch to it.
Prompts for a destination — \"Inbox\", or \"area/section\" under a configured
area, creating a new section if typed — then a title (optional for Inbox,
where the file is timestamped).  Seeds a `#+TITLE:'/`#+DATE:' header and
leaves point ready for the body."
  (let* ((choice (completing-read "Capture to (Inbox, or area/section): "
                                  (cons "Inbox" (systemhalted/org-section-dirs))))
         (inbox (string-equal choice "Inbox"))
         (reldir (if inbox
                     "00-inbox"
                   (systemhalted/org--validate-destination choice)))
         (dir (systemhalted/org-file reldir))
         (title (string-trim (read-string (if inbox "Title (optional): " "Title: "))))
         (stem (if (string-empty-p title)
                   (format-time-string "%Y-%m-%d-%H%M")
                 (systemhalted/org-slug title)))
         (path (systemhalted/org-unique-file dir stem)))
    (make-directory dir t)
    (set-buffer (find-file-noselect path))
    (goto-char (point-max))
    (insert "#+TITLE: " (if (string-empty-p title) stem title) "\n"
            "#+DATE: " (format-time-string "[%Y-%m-%d %a %H:%M]") "\n\n")
    (goto-char (point-max))))

(defun systemhalted/refile-note ()
  "Move the current note file (and its attachments) into a chosen area/section.
This is the directory-model replacement for `org-refile' — the weekly sweep
moves an inbox note into place by relocating its file.  Roll back completed
moves if any later step fails."
  (interactive)
  (unless (and buffer-file-name
               (file-in-directory-p buffer-file-name org-directory))
    (user-error "Not visiting a note under Organicely"))
  (let* ((target-rel
          (systemhalted/org--validate-destination
           (completing-read "Move note to: "
                            (systemhalted/org-section-dirs) nil nil)))
         (target-dir (systemhalted/org-file target-rel))
         (dest (systemhalted/org-unique-file
                target-dir (file-name-base buffer-file-name)))
         (old buffer-file-name)
         (attach (concat (file-name-sans-extension old) "-attachments"))
         (dest-attach
          (concat (file-name-sans-extension dest) "-attachments"))
         note-moved
         attachment-moved)
    (make-directory target-dir t)
    (save-buffer)
    (condition-case err
        (progn
          (rename-file old dest)
          (setq note-moved t)
          (when (file-directory-p attach)
            (rename-file attach dest-attach)
            (setq attachment-moved t))
          (set-visited-file-name dest nil t)
          (message "Moved to %s" (file-relative-name dest org-directory)))
      (error
       (let (rollback-errors)
         (when attachment-moved
           (condition-case rollback-error
               (rename-file dest-attach attach)
             (error (push (error-message-string rollback-error)
                          rollback-errors))))
         (when note-moved
           (condition-case rollback-error
               (rename-file dest old)
             (error (push (error-message-string rollback-error)
                          rollback-errors))))
         (if rollback-errors
             (error "Move failed: %s; rollback also failed: %s"
                    (error-message-string err)
                    (mapconcat #'identity (nreverse rollback-errors) " | "))
           (signal (car err) (cdr err))))))))

(defun systemhalted/journal ()
  "Open (creating if needed) today's per-day journal file for writing.
Journal entries are individual files under `50-journal/daily/' named
`YYYY-MM-DD.org'; a fresh file is seeded with a human-readable title like
\"5th June 2026, Friday\" and opened alone in book view for a distraction-free
writing session."
  (interactive)
  (let* ((day (string-to-number (format-time-string "%d")))
         (suffix (cond ((memq day '(11 12 13)) "th")
                       ((= (% day 10) 1) "st")
                       ((= (% day 10) 2) "nd")
                       ((= (% day 10) 3) "rd")
                       (t "th")))
         (title (format "%d%s %s, %s" day suffix
                        (format-time-string "%B %Y")
                        (format-time-string "%A")))
         (dir (systemhalted/org-file "50-journal/daily")))
    (make-directory dir t)
    (find-file (expand-file-name (format-time-string "%Y-%m-%d.org") dir))
    (delete-other-windows)
    (when (= (buffer-size) 0)
      (insert "#+TITLE: " title "\n"
              "#+DATE: " (format-time-string "[%Y-%m-%d %a]") "\n\n"))
    (goto-char (point-max))
    (unless (bolp) (insert "\n"))
    (unless (bound-and-true-p olivetti-mode)
      (systemhalted/book-view-toggle))))

(global-set-key (kbd "C-c J") #'systemhalted/journal)
#+end_src

** Soft guardrail: tasks belong in Reminders

The old three-file model enforced its boundaries with save-time /errors/. A
second brain does not need that: there is one rule, and breaking it hurts
nobody but future-you. The remaining guard is a =before-save-hook= that warns
and never blocks — the save always succeeds.

#+begin_src emacs-lisp
(defun systemhalted/org-warn-done-state ()
  "Warn (never block) when a file under `org-directory' holds a task.
Anything with TODO/IN-PROGRESS/DONE or SCHEDULED/DEADLINE has a done
state and belongs in Reminders, not in Organicely."
  (when (save-excursion
          (goto-char (point-min))
          (re-search-forward systemhalted/org-done-state-regexp nil t))
    (message "Note: this has a \"done\" state; it belongs in Reminders, not org.")))
#+end_src

** Directory seeding and per-file hook dispatch

=systemhalted/apply-org-soft-guard= attaches the done-state warning
buffer-locally to any file under =org-directory=.

=systemhalted/ensure-org-files= creates the area and section directories. It
runs from the main =:config= block — the moment Org first loads — so capture
and refile always have real directories to complete against, even on a machine
where =~/organicely/= does not exist yet. Nothing is seeded per file: a note
/is/ a file, so there is nothing to pre-populate.

#+begin_src emacs-lisp
(defun systemhalted/apply-org-soft-guard ()
  "Attach the soft done-state warning to files under `org-directory'."
  (when (and buffer-file-name
             (file-in-directory-p buffer-file-name org-directory))
    (add-hook 'before-save-hook #'systemhalted/org-warn-done-state nil t)))

(defun systemhalted/ensure-org-files ()
  "Create the Organicely area and section directories if missing.
Areas listed in `systemhalted/org-area-sections' get their section subdirs;
the rest are created flat.  New sections appear on demand via capture/refile."
  (make-directory org-directory t)
  (dolist (area systemhalted/org-area-dirs)
    (let ((sections (cdr (assoc area systemhalted/org-area-sections))))
      (if sections
          (dolist (sec sections)
            (make-directory (systemhalted/org-file (concat area "/" sec)) t))
        (make-directory (systemhalted/org-file area) t)))))
#+end_src

** Source-aware inbox capture

The target callback for the =s= capture template. If capture was launched from
a heading in some other Org file, that heading gains an =:ID:= and the note
lands under a =00-inbox/sources.org= heading whose =:SOURCE_ID:= matches — so
every note about one source stays grouped *even after the source is renamed*,
because the link is by ID, not text. From anywhere else it falls back to a flat
=* Inbox= heading.

Source notes are the one deliberate exception to "a note is a file": grouping
notes about one source under a shared heading earns them a shared file. The
=:PROPERTIES:= drawer is written inline rather than through Org's property API
because the heading does not exist yet.

#+begin_src emacs-lisp
(defun systemhalted/org-notes-target ()
  "Position point in 00-inbox/sources.org for a `file+function' capture target.
When capture is launched from an Org heading outside the inbox, ensure that
heading has an :ID: and file the new note under a top-level heading in the
inbox keyed by :SOURCE_ID:.  This groups every note about the same source
under one subtree even after the source is renamed.  When capture is launched
from anywhere else, fall back to the flat `* Inbox' heading."
  (let* ((src-buf (org-capture-get :original-buffer))
         (src-info
          (when (and src-buf (buffer-live-p src-buf))
            (with-current-buffer src-buf
              (when (and (derived-mode-p 'org-mode)
                         buffer-file-name
                         (not (systemhalted/org-buffer-file-p "00-inbox/sources.org"))
                         (ignore-errors (org-back-to-heading t) t))
                (cons (org-get-heading t t t t)
                      (org-id-get-create)))))))
    (goto-char (point-min))
    (cond
     (src-info
      (let ((title (car src-info))
            (id (cdr src-info)))
        (if (re-search-forward
             (format "^[ \t]*:SOURCE_ID:[ \t]+%s[ \t]*$" (regexp-quote id))
             nil t)
            ;; Stay on the heading line: org-capture appends the note to
            ;; the end of this subtree (point past it would misfile the
            ;; note under the next source heading).
            (org-back-to-heading t)
          (goto-char (point-max))
          (unless (bolp) (insert "\n"))
          (let ((start (point)))
            (insert "* " title "\n"
                    "  :PROPERTIES:\n"
                    "  :SOURCE_ID: " id "\n"
                    "  :END:\n")
            (goto-char start)))))
     (t
      (systemhalted/org-goto-or-create-heading "Inbox")))))
#+end_src

** Main Org configuration

Where everything above gets wired together.

*Keys.* =C-c c= captures globally. =C-c l= (=org-store-link=) and =C-c C-w=
(=systemhalted/refile-note=) are bound in =org-mode-map= only — the first so it
does not shadow the LSP =C-c l= prefix in code buffers, the second because
refiling here moves a file rather than a subtree, so there are no
=org-refile-targets= to maintain. There is deliberately no agenda key.

*Display.* Virtual heading indentation, hidden emphasis markers, a =" ..."=
fold marker, =C-c '= source edits in the same window, and =visual-line-mode= for
soft wrapping.

*No task vocabulary.* =org-todo-keywords= is nil, so =C-c C-t= has nothing to
offer. =org-confirm-babel-evaluate= stays on because this file's own Babel
blocks are evaluated on tangle.

*Capture.* Two templates. =c= Note creates a fresh note file through
=systemhalted/org-capture-file=; =s= Source note groups by =:SOURCE_ID:= in
=00-inbox/sources.org=. The journal has no template on purpose — =C-c J= is a
writing session, not a popup.

*Links.* =systemhalted/org-eww-links= sets =browse-url-browser-function=
buffer-locally, so URL links are EWW-first in Org buffers only; magit, help and
everything else keep the system browser. Obvious PDF targets go straight to the
PDF viewer, and URLs that only turn out to be PDFs after the response are
caught by the EWW handler further down. =C-c o= opens the link at point in the
real browser instead (=&= does the same inside EWW).

*Hooks.* =systemhalted/ensure-org-files= runs from =:config= — the moment Org
first loads — so the directories exist before anything can target them, without
putting Org in the startup path. =C-c a= and =C-c P= are explicitly unbound so
a reload in a long-running session clears the retired agenda and promotion
keys. Babel loads Emacs Lisp, Java, Python, Lua, and shell; Jupyter is opt-in
below.

** PDF tools — in-Emacs PDF reading

PDFs stay inside Emacs whether they arrive via =C-x C-f=, an Org =file:= link,
or a link followed in EWW. =pdf-tools= renders them; Org's "open PDFs
externally" rule is overridden; and EWW's =application/pdf= handler is replaced
with one that writes the bytes to a disposable file and visits it in
=pdf-view-mode=. That copy lives under =temporary-file-directory= and is
deleted when its buffer is killed — =C-x C-w= keeps one worth keeping.

#+begin_src sh
# Native dependencies for pdf-tools' epdfinfo helper:
# macOS, MacPorts:   sudo port install poppler automake pkgconfig
# macOS, Homebrew:   brew install poppler automake pkgconf
# Fedora:            sudo dnf install poppler-glib-devel automake pkgconf-pkg-config
# Ubuntu / Debian:   sudo apt install libpoppler-glib-dev automake pkg-config
#
# Then in Emacs, once per machine (and again after a poppler upgrade):
# M-x pdf-tools-install
#+end_src

The Lisp package installs from GitHub through =package-vc=; =:mode= and
=:magic= keep it unloaded until the first PDF buffer.

#+begin_src emacs-lisp
(require 'url-handlers)
(require 'url-parse)

(defcustom systemhalted/pdf-temp-directory temporary-file-directory
  "Directory for temporary PDFs downloaded for in-Emacs reading."
  :type 'directory
  :group 'systemhalted)

(defconst systemhalted/pdf-url-regexp "\\.pdf\\(?:[?#].*\\)?\\'"
  "Regexp matching URLs that explicitly end in a PDF filename.")

(defvar-local systemhalted/pdf-temp-file nil
  "Temporary PDF backing the current buffer, deleted when the buffer is killed.")

(defun systemhalted/pdf-url-p (url)
  "Return non-nil when URL explicitly names a PDF file."
  (and (stringp url)
       (let ((case-fold-search t))
         (string-match-p systemhalted/pdf-url-regexp url))))

(defun systemhalted/pdf--delete-file-if-present (file)
  "Delete FILE when it exists."
  (when (and (stringp file)
             (file-exists-p file))
    (delete-file file)))

(defun systemhalted/pdf--delete-temp-file ()
  "Delete the temporary PDF backing the current buffer, if any."
  (systemhalted/pdf--delete-file-if-present systemhalted/pdf-temp-file))

(defun systemhalted/pdf--url-filename (url)
  "Return a best-effort filename for URL."
  (let* ((path (if (stringp url)
                   (url-filename (url-generic-parse-url url))
                 ""))
         (name (file-name-nondirectory path)))
    (if (string= name "") "download.pdf" name)))

(defun systemhalted/pdf--make-temp-file (&optional hint)
  "Create a temporary PDF path, optionally seeded from HINT."
  (let* ((dir (file-name-as-directory
               (expand-file-name systemhalted/pdf-temp-directory)))
         (name (file-name-nondirectory (or hint "download.pdf")))
         (name (if (string= name "") "download.pdf" name))
         (stem (replace-regexp-in-string
                "[^[:alnum:]]+"
                "-"
                (file-name-base name)))
         (stem (if (string= stem "") "download" stem)))
    (make-directory dir t)
    (make-temp-file (expand-file-name (concat "systemhalted-" stem "-") dir)
                    nil
                    ".pdf")))

(defun systemhalted/pdf--visit-temporary-file (file &optional new-window)
  "Visit temporary PDF FILE and delete it when its buffer is killed.
If NEW-WINDOW is non-nil, display the buffer in another window."
  (let ((buffer (find-file-noselect file)))
    (with-current-buffer buffer
      (setq-local systemhalted/pdf-temp-file file)
      (add-hook 'kill-buffer-hook #'systemhalted/pdf--delete-temp-file nil t))
    (if new-window
        (pop-to-buffer buffer)
      (pop-to-buffer-same-window buffer))
    buffer))

(defun systemhalted/pdf-open-url (url &optional new-window)
  "Download PDF URL to a temporary file and open it in Emacs.
If NEW-WINDOW is non-nil, display the PDF in another window."
  (interactive (browse-url-interactive-arg "PDF URL: "))
  (let ((temp-file (systemhalted/pdf--make-temp-file
                    (systemhalted/pdf--url-filename url)))
        buffer)
    (unwind-protect
        (progn
          (url-copy-file url temp-file t)
          (setq buffer
                (systemhalted/pdf--visit-temporary-file temp-file new-window)))
      (unless buffer
        (systemhalted/pdf--delete-file-if-present temp-file)))
    buffer))

(defun systemhalted/org-browse-url (url &optional new-window)
  "Open URL in EWW, except that obvious PDFs stay in Emacs.
If NEW-WINDOW is non-nil, display the target in another window."
  (if (systemhalted/pdf-url-p url)
      (systemhalted/pdf-open-url url new-window)
    (eww-browse-url url new-window)))

(defun systemhalted/eww-display-pdf ()
  "Open the current EWW PDF response in Emacs."
  (let ((temp-file (systemhalted/pdf--make-temp-file
                    (systemhalted/pdf--url-filename
                     (plist-get eww-data :url))))
        (coding-system-for-write 'no-conversion)
        buffer)
    (unwind-protect
        (progn
          (write-region (point) (point-max) temp-file nil 'silent)
          (setq buffer (systemhalted/pdf--visit-temporary-file temp-file)))
      (unless buffer
        (systemhalted/pdf--delete-file-if-present temp-file)))
    buffer))

(with-eval-after-load 'eww
  (advice-add 'eww-display-pdf :override #'systemhalted/eww-display-pdf))

  :defer t
  :commands (pdf-tools-install pdf-view-mode)
  :mode ("\\.[pP][dD][fF]\\'" . pdf-view-mode)

** Tutorial: Using LaTeX

Reachable with =C-h T= -> /LaTeX/. Open a =.tex= file; the mode line should
show =LaTeX/P=. Plain =LaTeX= without the =/P= means =TeX-PDF-mode= is off and
builds will target DVI.

| Keys              | Command                     | What it does                                |
|-------------------+-----------------------------+---------------------------------------------|
| =C-c C-c=         | =TeX-command-master=        | run the default command (LatexMk -> PDF)    |
| =C-c C-a=         | =TeX-command-run-all=       | build, then view, in one step               |
| =C-c C-v=         | =TeX-view=                  | open the compiled PDF (forward SyncTeX)     |
| =C-c C-p C-p=     | =preview-at-point=          | inline-render the math/figure at point      |
| =C-c C-p C-d=     | =preview-document=          | inline-render every preview in the file     |
| =C-c C-p C-c C-p= | =preview-clearout-at-point= | remove the inline preview at point          |
| =C-c (=           | =reftex-label=              | insert a label                              |
| =C-c )=           | =reftex-reference=          | pick from existing labels and insert =\ref= |
| =C-c [=           | =reftex-citation=           | pick from .bib entries and insert =\cite=   |
| =C-c ==           | =reftex-toc=                | navigable table of contents                 |

*Producing a PDF.* =C-c C-c=, accept the =LatexMk= default with =RET=. On
success =C-c C-v= opens the PDF inside Emacs; =C-x C-w= from that buffer keeps
a copy elsewhere.

*Inline math previews.* Point inside a math environment, =C-c C-p C-p=. The
source is replaced by a rendered image and restores itself as soon as you edit
it. =C-c C-p C-d= does the whole file, =C-c C-p C-c C-p= clears the one at
point.

*RefTeX.* =C-c (= inserts a label with a context-appropriate prefix, =C-c )=
picks an existing label and inserts =\ref=, =C-c [= picks a =.bib= entry and
inserts =\cite=, =C-c == shows a navigable table of contents.

*Org -> PDF.* =C-c C-e l p= in any =.org= file, through the same latexmk
invocation.

*** Common failure modes

- /"No such file or directory, latexmk"./ TeX Live is not on Emacs's =PATH=.
  Check =M-x executable-find RET latexmk=; if nil, install it and restart Emacs
  so =exec-path-from-shell= picks up the new =bin= directory.
- /"File `foo.sty' not found"./ Unlikely on a full distribution; otherwise
  install the collection the error names (=texlive-<collection>=).
- /"PDF Tools are not available", or =epdfinfo= fails to build./ Install the
  native dependencies from the PDF tools section and run
  =M-x pdf-tools-install=. Rerun it after a =poppler= upgrade.
- /Inline preview renders a blank box./ =preview-latex= shells out to =dvipng=
  or =gs=; check =M-x executable-find RET gs=.

** Borderless frames sized to the monitor

Removing the title bar makes native maximization the wrong primitive: on macOS
an =undecorated= frame stops tracking per-display usable bounds reliably. So
each graphical frame is made borderless and resized to its monitor's
=workarea=, falling back to =geometry= where the window manager exposes no
separate usable area. The helper is interactive, so it can be re-run after
moving a frame between monitors. On Omarchy hosts
(=systemhalted/omarchy-owned-ui=) the whole block is skipped and the tiling WM
owns geometry.

#+begin_src emacs-lisp
  (defun systemhalted/fill-frame-to-monitor-workarea (&optional frame)
    "Make FRAME borderless and size it to its monitor's usable workarea."
    (interactive)
    (let ((frame (or frame (selected-frame))))
      (when (display-graphic-p frame)
        (let* ((attrs (frame-monitor-attributes frame))
               (workarea (or (alist-get 'workarea attrs)
                             (alist-get 'geometry attrs))))
          (when (and (listp workarea) (= (length workarea) 4))
            (let ((left (nth 0 workarea))
                  (top (nth 1 workarea))
                  (width (nth 2 workarea))
                  (height (nth 3 workarea)))
              (modify-frame-parameters frame '((fullscreen . nil)
                                               (undecorated . t)))
              ;; `set-frame-size' expects the text area, so subtract the
              ;; frame chrome Emacs still keeps inside the window.
              (let ((text-width (max 1 (- width (- (frame-pixel-width frame)
                                                   (frame-text-width frame)))))
                    (text-height (max 1 (- height (- (frame-pixel-height frame)
                                                     (frame-text-height frame))))))
                (set-frame-position frame left top)
                (set-frame-size frame text-width text-height t))))))))

  (unless (bound-and-true-p systemhalted/omarchy-owned-ui)
    ;; ns-use-native-fullscreen is the NeXTSTEP (macOS) fullscreen mode
    ;; toggle and is unbound on Linux; the workarea sizing above handles
    ;; startup geometry without a title bar.
    (when (eq system-type 'darwin)
      (setq ns-use-native-fullscreen t))
    (dolist (alist-var '(initial-frame-alist default-frame-alist))
      (set alist-var (assq-delete-all 'fullscreen (symbol-value alist-var)))
      (set alist-var (assq-delete-all 'undecorated (symbol-value alist-var))))
    (add-to-list 'initial-frame-alist '(undecorated . t))
    (add-to-list 'default-frame-alist '(undecorated . t))
    (add-hook 'window-setup-hook #'systemhalted/fill-frame-to-monitor-workarea)
    (add-hook 'after-make-frame-functions
              #'systemhalted/fill-frame-to-monitor-workarea)
    (dolist (frame (frame-list))
      (systemhalted/fill-frame-to-monitor-workarea frame)))
#+end_src

** Dired, fonts, and theme

In Dired, =c= creates an empty file. GUI frames use Fira Code and Cantarell at
15 pt when available; the helper re-runs for new client frames. On Omarchy the
host owns those faces and only the Nerd Font icon fallback is added.

The fallback is registered on both the current and the default fontset, so it
outranks the default face's catch-all unicode mapping in new frames too. Prefer
a =Mono= Nerd Font, or icons render double-width.

No theme loads at startup; =C-c T= opens Consult's picker with previews. On
Omarchy a manual choice lasts until the host changes the theme again.

#+begin_src emacs-lisp
  (defvar systemhalted/omarchy-owned-ui nil
    "When non-nil, the host system (Omarchy) owns Emacs UI styling.
  The config then skips setting its own default and variable-pitch fonts;
  the startup theme is deferred regardless. Set this in
  ~/.config/emacs/init.el before loading this config.")

  (with-eval-after-load 'dired
    (define-key dired-mode-map (kbd "c") #'dired-create-empty-file))

  (defconst systemhalted/gui-default-font-candidates
    '("Fira Code" "FiraCode Nerd Font")
    "Monospaced fonts to try for the default face, in order.")

  (defconst systemhalted/gui-nerd-font-candidates
    '("FiraCode Nerd Font Mono"
      "MesloLGS NF"
      "MesloLGS Nerd Font Mono"
      "JetBrainsMono Nerd Font Mono"
      "MesloLGM Nerd Font Mono")
    "Nerd Fonts to try for Private Use Area glyph fallback, in order.")

  (defconst systemhalted/gui-nerd-font-ranges
    '((#xe000  . #xf8ff)    ; BMP Private Use Area (Powerline, Devicons)
      (#xf0000 . #xfffff)) ; Supplementary PUA-A (Material Design, etc.)
    "Unicode ranges that should render with the Nerd Font fallback.")

  (defun systemhalted/apply-graphical-frame-fonts (&optional frame)
    "Apply GUI fonts and icon fallbacks to FRAME."
    (let ((frame (or frame (selected-frame))))
      (when (display-graphic-p frame)
        (with-selected-frame frame
          (unless (bound-and-true-p systemhalted/omarchy-owned-ui)
            (let ((mono-font (seq-find (lambda (name) (find-font (font-spec :name name)))
                                       systemhalted/gui-default-font-candidates)))
              (when mono-font
                (set-face-attribute 'default frame :font mono-font :height 150)))
            (when (find-font (font-spec :name "Cantarell"))
              (set-face-attribute 'variable-pitch frame :font "Cantarell" :height 150)))

          ;; Register on both the default fontset (t, inherited by future
          ;; frames) AND the current frame's fontset (nil) so the Nerd Font
          ;; takes priority over the default face's catch-all unicode mapping.
          (let ((nerd-font (seq-find (lambda (name) (find-font (font-spec :name name)))
                                     systemhalted/gui-nerd-font-candidates)))
            (when nerd-font
              (dolist (range systemhalted/gui-nerd-font-ranges)
                (set-fontset-font t range nerd-font nil 'prepend)
                (set-fontset-font nil range nerd-font nil 'prepend))))))))

  (add-hook 'after-make-frame-functions #'systemhalted/apply-graphical-frame-fonts)
  (systemhalted/apply-graphical-frame-fonts)

** Terminal emulator — Ghostel

[[https://github.com/dakra/ghostel][Ghostel]] wraps Ghostty's =libghostty-vt= engine: ~75 MB/s throughput, Kitty

** Tutorial: Using Ghostel

Reachable with =C-h T= -> /Ghostel/.

*Opening terminals.* =C-c m= opens the terminal or switches to it. =C-u C-c m=
always makes a fresh one; a numeric prefix (=M-3 C-c m=) opens the numbered
=*ghostel*<3>=. =C-x p m= roots one at the project; /Ghostel/ also appears in
the =C-x p p= menu.

*Input modes.* Five, shown in the mode line. *Semi-char* (default) sends almost
everything to the shell but keeps =C-c=, =C-x=, and =M-x= for Emacs. *Char*
sends /everything/ — needed by TUI apps that bind those themselves. *Emacs*
sends nothing; the buffer reads normally while the terminal runs underneath.
*Copy* freezes the screen for selection with ordinary motion keys. *Line* is
comint-style: compose in Emacs, send with =RET=.

| Keys      | Command                    | What it does                                  |
|-----------+----------------------------+-----------------------------------------------|
| =C-c C-j= | =ghostel-semi-char-mode=   | back to the default semi-char mode            |
| =C-c M-d= | =ghostel-char-mode=        | char mode: every key goes to the terminal     |
| =C-c C-e= | =ghostel-emacs-mode=       | Emacs mode: no keys go to the terminal        |
| =C-c C-t= | =ghostel-copy-mode=        | copy mode: select/kill from the scrollback    |
| =C-c C-l= | =ghostel-line-mode=        | line mode: comint-style line editing          |
| =C-c C-c= | =ghostel-send-C-c=         | send a literal =C-c= (interrupt)              |
| =C-c C-z= | =ghostel-send-C-z=         | send a literal =C-z= (suspend)                |
| =C-c C-d= | =ghostel-send-C-d=         | send a literal =C-d= (EOF)                    |
| =C-c C-q= | =ghostel-send-next-key=    | send the next key verbatim, whatever it is    |
| =C-c C-y= | =ghostel-paste=            | paste into the terminal                       |
| =C-y=     | =ghostel-yank=             | yank from the kill ring (semi-char mode)      |
| =C-c M-w= | =ghostel-copy-all=         | copy the whole scrollback to the kill ring    |
| =C-c M-l= | =ghostel-clear-scrollback= | clear the scrollback                          |
| =C-c M-p= | =ghostel-previous-prompt=  | jump to the previous shell prompt (OSC 133)   |
| =C-c M-n= | =ghostel-next-prompt=      | jump to the next shell prompt                 |
| =C-c C-p= | =ghostel-previous-hyperlink= | jump to the previous link / file:line ref   |
| =C-c C-n= | =ghostel-next-hyperlink=   | jump to the next link / file:line ref         |
| =C-s=     | =consult-line=             | search the buffer (this config's remap)       |

*Calling Emacs from the shell.* The injected integration defines
=ghostel_cmd FUNCTION [ARGS...]=, which calls an Elisp function whitelisted in
=ghostel-eval-cmds=. With the additions above:

#+begin_example
ghostel_cmd magit-status-setup-buffer      # magit for the current directory
ghostel_cmd find-file-other-window README.md
ghostel_cmd dired-other-window .
#+end_example

*Powerline prompts and fonts.* Powerlevel10k and Starship draw separators and
icons from the Nerd Fonts Private Use Area. The /Dired, fonts, and theme/
section registers a fontset fallback for exactly those codepoints, so the
glyphs render single-width inside Ghostel — but only if one of the fonts in its
lookup list is installed:

- macOS: =brew install --cask font-fira-code-nerd-font= or =sudo port
  install firacode-nerd-font-fonts= (Powerlevel10k's own =p10k
  configure= can also install /MesloLGS NF/).
- Fedora and Ubuntu/Debian: Nerd Fonts are not in the official repos —
  download /FiraCode/ from [[https://www.nerdfonts.com/font-downloads][nerdfonts.com]], unzip into
  =~/.local/share/fonts/=, and run =fc-cache -f=.

*** Common failure modes

- /=M-x ghostel= fails on first run with a download error./ The native
  module is fetched from GitHub Releases on first use; check network
  access to github.com and retry. =M-x ghostel-module-install= retries
  the download explicitly.
- /Prompt icons render as empty boxes./ No font in the fallback list
  is installed, so the fontset registration no-opped. Install one of
  the fonts above and restart Emacs (or re-run =C-c r= and open a new
  frame).
- /Separators render but overlap or double-width./ A non-Mono Nerd
  Font variant is winning for the PUA range. The fallback list prefers
  =Mono= variants precisely to force single-cell icon width; make sure
  one is installed so it outranks the proportional variant.
- /=ghostel_cmd= prints "unknown eval command"./ The function isn't
  whitelisted — add it to =ghostel-eval-cmds= in the config block
  above and reload.

** Wordwise — Kindle-style inline vocabulary hints

[[https://github.com/systemhalted/wordwise.el][wordwise.el]] annotates uncommon English words with a short dictionary
definition on a phantom line above them — Kindle's Word Wise, in Emacs. A
bundled five-tier frequency list decides what counts as uncommon,
=wordwise-difficulty= (1–5) tunes the density, and definitions come from
dict.org over one asynchronous connection. It grew up as a block in this file
and was extracted into its own package.

Loaded through the shared hybrid pattern (=WORDWISE_EL_DIR=). The package ships
an Info manual: =package.el= registers it automatically for an installed copy,
but a plain load-path checkout gets no activation, so the local branch adds the
directory to =Info-additional-directory-list= itself. The definition cache is
registered with savehist up in the Savehist section, eagerly, so a session that
never loads Wordwise does not drop it.

=C-c w= toggles; =M-x wordwise-set-difficulty= changes the density.

#+begin_src emacs-lisp
(systemhalted/use-personal-package wordwise
    "WORDWISE_EL_DIR" "https://github.com/systemhalted/wordwise.el"
    ;; package.el registers Info manuals only for installed packages; a
    ;; load-path checkout needs its dir file put on Info's search path by hand
    ;; for C-h R to find the wordwise manual.
    (:init (with-eval-after-load 'info
             (add-to-list 'Info-additional-directory-list
                          (systemhalted/personal-package-checkout
                           "WORDWISE_EL_DIR"))))
  :bind ("C-c w" . wordwise-mode))
#+end_src

** Tutorial: Using Wordwise

Reachable with =C-h T= -> /Wordwise/.

*Enabling.* =C-c w= toggles =wordwise-mode= in =org-mode=, =nov-mode=,
=markdown-mode=, =gfm-mode=, and =eww-mode=; elsewhere it declines with a
message. Lookups go to dict.org over one asynchronous connection, so typing and
scrolling never wait on the server. Definitions and confirmed misses are cached
across restarts; timeouts stay session-local and retry after a cooldown, and
cached hints keep working offline.

*Difficulty.* 1–5, default 3, controlling how many words are annotated:

| Level | Annotates words outside the top… | Typical density        |
|-------+----------------------------------+------------------------|
|     1 | 10 000 (very rare only)          | fewest annotations     |
|     2 | ~7 000                           |                        |
|     3 | ~5 000 (default)                 | moderate               |
|     4 | ~3 000                           |                        |
|     5 | ~1 000 (most annotations)        | many annotations       |

=M-x wordwise-set-difficulty= changes it and redraws immediately.

*How definitions appear.* A faint line above the word, indented to its column:

#+begin_example
                    directing
This is a guiding principle for our work.
#+end_example

*Prose only.* Source blocks, inline code, drawers, property lines, links, and
code-like identifiers (camelCase, ALL_CAPS, anything with underscores or
slashes) are skipped.

*Scrolling.* Newly visible regions are scanned once redisplay settles, across
every window showing the buffer. Cached definitions appear instantly; new words
join a deduplicated queue fetched one at a time.

*Ignoring words.* =M-x wordwise-ignore-word= with point on the word adds it to
=wordwise-ignored-words=, saved through Customize.

| Keys          | Command                                   |
|---------------+-------------------------------------------|
| =C-c w=       | Toggle Wordwise mode on/off                |
| =M-x wordwise-set-difficulty= | Change annotation density |
| =M-x wordwise-ignore-word=    | Ignore word at point      |
